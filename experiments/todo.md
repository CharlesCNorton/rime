2. **Self-modifying hardware via ECP5 SED.** *(Feasibility risk: ECP5 SEDGA primitive provides soft error detection but does NOT expose write access to configuration SRAM. Self-modification would require the SSPI/MSPI reconfiguration path, which overwrites the entire bitstream — not individual LUTs. Partial reconfiguration is not supported on ECP5. This experiment may need to be reformulated as an external-driven mutation loop where the host synthesizes, programs, and measures each generation.)* The ECP5 has a soft error detection block and access to its own configuration SRAM through internal primitives. Build a circuit that reads its own bitstream, mutates a defined region of LUTs (changing truth tables), writes the mutation back, and observes the behavioral change — without JTAG or external tools. Start with N copies of a 4-input LUT implementing function F. Randomly mutate one LUT's truth table per generation. Measure how many mutations it takes before the circuit's behavior deviates from the original. This gives the empirical neutral network size for a specific circuit in a specific technology — how much of the configuration space is functionally equivalent.

3. **Parallel nondeterministic search.** Build a nondeterministic finite automaton where every state is a physical register and every transition is a physical wire. On each clock cycle, all active states propagate simultaneously through all valid transitions. A k-state NFA on an n-character input explores all 2^k possible state subsets in n clock cycles. Compare to the deterministic powerset-constructed DFA on the same fabric. Measure the LUT cost and cycle count for both. At what NFA complexity does the parallel NFA become more resource-efficient than the equivalent DFA? This measures the physical cost of nondeterminism when implemented as parallel hardware rather than sequential backtracking.

4. **Propagation delay computation.** Build a circuit where the output is determined by signal arrival time, not logic values. Route a signal through two paths of different LUT-chain lengths. A race arbiter at the convergence point outputs 0 or 1 depending on which path arrives first. Build an N-bit comparator where each bit is a race arbiter encoding the comparison through differential delay. The computation completes in propagation time — sub-nanosecond for the full comparison. Measure throughput against a conventional registered comparator. Time-domain computing on the ECP5's ~300ps/LUT fabric.

5. **Massively parallel cellular automaton.** 10,000 cells (100×100 grid) as flip-flops with combinational next-state logic. All cells update simultaneously every clock cycle at 25 MHz — 250 billion cell-updates per second. ~2 LUTs per cell = 20K LUTs. Run Rule 110, Langton's λ sweep, Game of Life. Measure the exact cycle at which a structure first appears (glider, spaceship, oscillator) across thousands of random initial conditions with cycle-perfect determinism. Study the statistics of first-appearance times. Sequential update order changes CA behavior; simultaneous update is ground truth.

6. **Ring oscillator network as physical dynamical system.** N ring oscillators (3-5 inverting LUTs each, oscillating at ~100-400 MHz depending on chain length) weakly coupled through AND or XOR gates. A physical analog of a Kuramoto oscillator network. Use fast counters to sample frequency and phase over time. Do the oscillators synchronize? At what coupling strength? Does the transition match the Kuramoto model's critical coupling threshold? Oscillation frequencies depend on process variation across the die — physically nondeterministic. Coupling topology is reconfigurable (ring, star, all-to-all, small-world).

7. **Thermodynamic cost of computation via toggle counting.** Two circuits computing the same function (8-bit sort of 16 elements): one conventional, one using low-activity adiabatic-style encoding (Gray code paths, balanced logic trees). Instrument both with toggle counters on every internal net. Run identical inputs, compare total toggle counts. The ratio gives the empirical Landauer gap — how far each implementation is from the thermodynamic minimum number of bit erasures. Build a third implementation using logically reversible Toffoli gates and measure its toggle count. Does logical reversibility reduce physical switching activity on FPGA fabric, or does ancilla/garbage overhead negate the savings?

8. **Hardware-evolved truth tables.** *(Feasibility risk: same ECP5 partial reconfiguration limitation as #2. Each generation requires a full bitstream write via RIME flash service + reload. At ~33s per generation this limits to ~100 generations/hour. The Frost or Slush configurable grids provide a faster alternative: truth tables can be rewritten over UART in seconds without FPGA resynthesis.)* Genetic algorithm where the genotype is a set of LUT truth tables and the phenotype is circuit behavior. 64 random 4-input LUT configurations in a fixed 4×4 grid topology. Fitness function: implement 4-bit parity. Mutate truth tables, evaluate fitness by clocking test vectors through the physical circuit, select, breed. LUT reconfiguration through the ECP5's internal configuration interface — each generation physically rewrites the circuit and evaluates it on silicon. Adrian Thompson's 1996 Xilinx experiment showed intrinsic evolution exploits non-digital phenomena (parasitic coupling, analog behavior). Nobody has replicated this on ECP5. Does intrinsic evolution on ECP5 discover solutions that exploit non-digital physics, and are those solutions portable to a different ECP5 chip with different process variation?

9. **Reversible processor with physical reversal.** A complete reversible processor where every gate is Toffoli or Fredkin and every operation preserves all input information. Garbage bits occupy physical registers. Run a sorting algorithm forward to completion, then reverse the datapath (feed outputs back as inputs, apply the inverse instruction sequence) and verify exact recovery of the original input. How many additional LUTs does full reversibility cost? How much additional switching activity? Does the circuit recover the input perfectly, or do physical timing issues (glitches, metastability) introduce irreversibility that the logical design doesn't predict? An open question in thermodynamics of computation.

10. **Computational substrate comparison.** Implement one algorithm (matrix multiply, SHA-256, or FFT) in three architectures on the same ECP5 die simultaneously: (a) the RIME-I soft CPU running hand-assembled RV32I, (b) a pure dataflow architecture with no program counter where data tokens flow through processing elements that fire when all inputs arrive, (c) a fully unrolled spatial pipeline where the entire computation is one combinational circuit producing the answer in a single propagation delay. Measure wall-clock time, LUT count, flip-flop count, and toggle activity for all three. Scale the problem size until each architecture hits its resource ceiling. An empirical Pareto frontier of architecture vs resource vs performance on a single technology node.

11. **Program space geometry.** 200 parallel interpreter circuits (~60 LUTs each), all executing different programs on the same input simultaneously. One instruction step per clock across all interpreters. 46,656 programs of length 6 in ~37,000 cycles. The regression test found a bimodal cliff-plateau structure at length 4 (66% identical neighbors, 22% maximally different). Length 6 tests whether that structure persists at scale.

12. **Computational metabolism.** 64 parallel interpreter circuits, all organisms executing on the same test input simultaneously. The evaluation inner loop drops from 512 sequential runs to 8 parallel rounds. 100,000+ generations in under a minute. The regression test found that metabolic selection eliminates inefficiency instantly but never removes dead code. Longer runs test whether replication-cost pressure (penalizing genome length) eventually drives compaction.

13. **Partition function of program space.** 200 parallel interpreters enumerate program space. Each reports halt/loop and output value. The CPU computes exp(-E/T) and accumulates Z(T). 2,300 batches × ~10 cycles per temperature value at length 6. Sweep 64 temperatures in under a second. Locate the specific heat peak where the dominant program class transitions from halting to looping.

14. **Self-referential complexity collapse.** The Kolmogorov estimator runs as a fabric interpreter array — 200 interpreters enumerating candidate programs in parallel. The CPU handles the self-modification loop: read current program, feed it as target to the estimator, get K back, try removing one instruction, re-estimate, accept if K decreased. Fabric acceleration of the inner search enables hundreds of collapse iterations per second.

15. **Computational temperature.** 200 parallel interpreters with per-interpreter unique-state counters in distributed RAM (~16 extra LUTs each). Each runs a program for 256 steps, counting distinct (A, B, PC) states visited. T_comp = unique states / total steps. 46,656 programs in 60,000 cycles. The full temperature distribution of a program space in one pass. Locate the phase boundary between frozen and liquid programs.

16. **Irreversibility gradient.** 50 parallel interpreters with 256-entry trace buffers in BRAM. After execution, a second-pass circuit reads traces backward and measures preimage size at each step — how many distinct prior states map to the current state. The irreversibility curve per program is computed in hardware and classified by shape: collapsing (increasing preimage), crystallizing (decreasing preimage), or flat.

17. **Transition topology.** 200 parallel interpreters, each running one program from all 256 initial states to build the complete transition function f: S→S. The CPU computes fixed points, cycle decomposition, connected components, and graph isomorphism class from each 256-entry transition table. 600K cycles for the full length-6 program space.

18. **Computational fossil record.** 50 parallel interpreters with trace buffers. Run a program forward, recording all states. From the final state alone, a fabric reconstruction circuit attempts reversal by testing all candidate instructions backward. 6 candidates per step evaluated in one clock cycle. Reconstruction fidelity — fraction of trace correctly recovered — measures the thermodynamic arrow of time for that program.

19. **Emergence discriminator.** 200 parallel interpreters evaluate all N+1 variants of a program simultaneously: the full program plus N single-instruction knockouts. For length-6 programs: 7 variants × 16 inputs per batch, 234 batches. A program is emergent if no single instruction's contribution explains the output but the program collectively does. Full emergence census of a 46,656-program space in ~1 ms.

20. **Syntax-semantics phase transition.** 200 parallel mutant copies of a reference program, each with independent random instruction replacements at mutation rate M. All execute simultaneously. Sweep M from 0 to 1 in 64 steps. The full error threshold curve for one program in 26 ms. Run 100 reference programs to map how M_c (the critical mutation rate where behavior collapses) varies across program space.

21. **Stochastic neural network in gates.** The 4→6→2 XOR network built from AND gates (multiplication), MUX (addition), and LFSRs (bitstream generation). 8 copies with different bitstream lengths (16-2048) running simultaneously. 25 million inferences per second from ~200 LUTs. The full precision/throughput Pareto curve measured in a single 4 ms run with all 8 bitstream lengths producing data in parallel.

22. **Cellular automaton — full rule census.** 1,024 cells (32×32) as flip-flops. All update simultaneously per clock tick. 200 generations in 8 μs. Sweep all 262,144 totalistic rules in under 5 seconds with population count and spatial entropy measured in hardware after each run.

23. **Reservoir computing with physical oscillator dynamics.** 32 ring oscillators with coupling XOR gates between neighbors. Oscillation frequencies depend on ECP5 routing delays and process variation — nondeterministic per synthesis run. The reservoir's computational power comes from propagation delay jitter and coupling dynamics that exist only in physical hardware. ~250 LUTs for 32 nodes. Push to 128-256 nodes for reservoir sizes competitive with published work.

24. **Intrinsic computation at wire speed.** 64 flip-flops implementing 1D CA rules with per-cell 3-generation history buffers and 8-entry pattern counter arrays (~30 LUTs/cell = 1,920 total). Statistical complexity computed in hardware as the lattice evolves. 10 million random initial conditions at 200 cycles each in 80 seconds. Builds the full statistical distribution of complexity emergence times across initial conditions.

25. **Kolmogorov / Solomonoff / Omega — parallel interpreters.** 200 interpreter circuits running different programs simultaneously. Push to length 8 (390,625 programs) in 20 ms. The same interpreter array serves all three experiments — the difference is what the CPU does with the halt/output results. At length 8, output coverage approaches meaningful levels where the complexity distribution, algorithmic probability, and halting fraction all become more than toy measurements.

26. **Photonic mesh — hardware pipeline.** 6 MZI stages using ECP5 MULT18X18D hard multipliers (12 of 28 available). 18-bit precision with zero LUT cost for multiplication. 25 million mesh evaluations per second. Sweep 1 million random phase configurations in 40 ms. Push to a 6×6 mesh (15 MZIs, 30 multipliers) where accumulated fixed-point error over longer optical paths becomes the measurement target.

27. **Tile assembly — parallel attachment.** 16×16 grid of registers with combinational attachment logic evaluating all 256 cells simultaneously per clock cycle. 1 million random tile systems in 40 seconds. Statistical characterization of the tile-system-to-shape mapping at a sample size where the probability distribution over final structures becomes well-resolved.

28. **Reversible computing — toggle measurement in fabric.** An 8-bit adder built from Toffoli gates as LUTs with a mode signal controlling dataflow direction. Forward computation, output capture, reverse mode, input recovery — all in fabric without CPU involvement. Toggle counters on internal nets measure physical switching events, which may differ from logical predictions due to glitch propagation, routing asymmetry, and combinational delay differences between forward and reverse paths.

29. **Homomorphic logic — hardware modular arithmetic.** Modular multiply/add/subtract (mod 251) using ECP5 DSP blocks. Encrypted AND becomes a modular multiplier, encrypted XOR becomes a modular adder. 100,000 trials per gate depth for proper confidence intervals on the accuracy degradation curve as a function of circuit depth and noise accumulation.

30. **Wheeler it-from-bit — parallel lattice instances.** 10+ simultaneous 256-cell lattice instances (~1,500 LUTs each) with BFS wavefronts advancing one layer per clock cycle. 10,000 trials for statistical power to test whether the consistency rate and final lattice configuration depend on seed position, seed value, and measurement order.
