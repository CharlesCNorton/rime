# RIME Images

Each subdirectory is a standalone FPGA image that can be built with `python icepi_helper.py build <name> --clean`.

## Service Image

| Image | Size | Purpose |
|-------|------|---------|
| `rime` | ~6,500 LUTs | Flash + SDRAM service (27 commands, chunked staging, diagnostics) |

## Experiments

Experiments are standalone HDL designs that use the full FPGA. Load via RIME's install workflow or SRAM load.

| Image | Size | Purpose |
|-------|------|---------|
| `ember` | ~9,500 LUTs | Hardware TRNG: 192 ring oscillators, AES-128-CBC, NIST health tests |
| `trng` | ~4,000 LUTs | Simpler hardware TRNG from ring oscillator phase jitter |
| `metastability` | ~3,000 LUTs | ECP5-25F metastability measurement |
| `entropy-source` | — | Ring oscillator entropy source characterization |
| `rf-sensor` | — | Ring oscillator RF sensitivity probe |
| `ring-survey` | — | Ring oscillator frequency survey across die |
| `seu-detector` | — | Single-event upset detection via TMR ring oscillators |
| `thermal-geometry` | — | Thermal gradient measurement via ring oscillator placement |
| `power-calibration` | — | Ring oscillator power consumption characterization |

LUT counts are approximate and rounded to the nearest 500. Synthesize for exact figures.

## Required Files Per Experiment

Every experiment directory must contain:

| File | Required | Purpose |
|------|----------|---------|
| `top.sv` | yes | Top-level HDL module (must be named `top`) |
| `README.md` | yes | Methodology, results, interpretation, resource usage |
| `build.json` | if needed | Custom nextpnr flags (e.g. `--ignore-loops` for ring oscillators) |
| `results_raw.*` | yes | Raw UART capture from the hardware run — the primary evidence |
| `parse_results.py` | yes | Script that reads raw output and reproduces the analysis |

Optional:

| File | Purpose |
|------|---------|
| `results_*.bin` | Additional raw captures from alternative approaches |
| `*.sv` | Supporting HDL modules (instantiated by top.sv) |
| `bitstream.bit` | Built bitstream (gitignored, regenerated by build) |
| `bitstream.json` | Synthesis intermediate (gitignored) |
| `bitstream.config` | P&R intermediate (gitignored) |

## README Template

```markdown
# <Experiment Name>

One-sentence summary of what was measured.

## Result

The headline finding, stated directly.

## Method

How the measurement works. What the HDL does. What physical phenomenon
is being exploited or measured. Enough detail that someone unfamiliar
with the board could understand and reproduce.

## Hardware

- Board and FPGA part
- Clock configuration
- Key module parameters (ring oscillator length, chain depth, etc.)
- Sample count and accumulation time

## Resource Usage

- LUT4: N / 24,288 (X%)
- DP16KD: N / 56
- Fmax: N MHz (sys_clk M MHz)

## Results

Raw data summary. If the result is a distribution, describe its shape.
If a bound, state the derivation. Reference the parse script.

```
python parse_results.py results_raw.*
```

## Files

List every file in the directory and its role.

## Reproducing

Exact commands to build, load, capture, and analyze.
```

## Rules

- The experiment HDL must not modify any RIME base files (core/, service modules, host tools).
- The experiment owns the entire FPGA when loaded. It does not coexist with a service image.
- Raw results must be committed. The parse script must reproduce the analysis from the raw data alone.
- The README must be written for someone with no prior knowledge of RIME or the IcePi Zero board.
- No second-person voice. No internal debugging history. No defensive framing.
